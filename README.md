# Libas-e-Makhna Website

A simple inspiration-gallery website for Libas-e-Makhna.

## What visitors can do
- Browse photographs of makhnas previously made and delivered.
- Use the gallery filters to explore prints, colours and finishes.
- Contact Azra Mujawar on WhatsApp to discuss a similar custom order and request a personalised quote.

## Important
- Gallery photographs are examples of previous work, not ready-made stock.
- Prices are not displayed on the website; the owner shares quotes directly.
- There is no cart, checkout, stock listing or online customisation form.

## Files
- `index.html` — page content, headings, navigation and sections.
- `styles.css` — colours, layout, typography and responsive styling.
- `app.js` — gallery data, filters and WhatsApp enquiry message.
- `assets/` — gallery photographs. Keep the existing filenames and folder structure so image paths continue to work.

## Local preview
Open `index.html` in a browser. Alternatively, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.
