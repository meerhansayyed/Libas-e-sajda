# Libas-e-Makhna Website

This is a sample-gallery website for Libas-e-Makhna.

## What the website does
- Shows photos of makhnas already made and delivered.
- Does not display prices.
- Does not have a cart, checkout, or online customisation form.
- Lets visitors contact the owner on WhatsApp to ask about prices.

## Files you can edit
- `index.html` — page text, headings, navigation and sections. Each HTML tag is on a separate line to make it easier to find and edit.
- `styles.css` — colours, spacing, fonts, layout and mobile styling.
- `app.js` — gallery behaviour and WhatsApp enquiry messages.
- `assets/` — sample makhna photographs.

## Open the website
Open `index.html` in a browser.

If needed, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.
